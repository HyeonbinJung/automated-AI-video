## 📌 개요

질문 다섯 개(**스토리 → 애니메이션 기법 → 캐릭터 → 장면 수 → Launch**)에 답하면 AI가 스토리를 다듬고, 캐릭터를 만들고, 스토리보드를 그리고, 장면마다 영상을 만들어 하나의 MP4로 합칩니다. 가장 싼 모델을 쓰고, 모든 유료 단계는 **최악의 원가 기준으로 선결제**해서 손해가 나지 않습니다.

---

## 🧭 사용 방법

| 단계 | 내용 |
|---|---|
| 1. 스토리 | 500자 이내로 대충 써도 AI가 개선 |
| 2. 애니메이션 기법 | 강한 훅 · 반전 엔딩 · 무한 루프 · 감동 · 코미디 · ASMR |
| 3. 캐릭터 | 설명하면 예시 캐릭터를 보여주고, 그대로 쓰거나 수정 요청 |
| 4. 장면 수 | 7 · 10 · 13개 (장면당 3~7초) → 스토리보드 확인 |
| 5. Launch | 장면 영상 생성 → 최종 MP4 |

언어: 한국어, English (US / India), हिन्दी, Español, 日本語, Bahasa Indonesia — 화면과 생성되는 스토리·자막 모두 선택한 언어로 나옵니다.

## 💰 가격

| 항목 | 가격 (부가세 포함) |
|---|---|
| 캐릭터 만들기 / 다시 만들기 | 100원 |
| 7 / 10 / 13장면 패키지 (스토리보드 + 모든 장면 영상) | 1,000 / 1,300 / 1,700원 |
| 스토리보드 다시 짜기 | 100~200원 |
| 장면 하나 다시 만들기 | 200원 |

영상 한 편 1,100원(7장면) ~ 1,800원(13장면). 장면 길이 최대, DeepSeek 최대 출력, 단가·환율 +10%, 부가세와 카드 수수료를 넣은 최악의 경우에도 영업이익률 20% 이상입니다. AI 비용 없이 실패한 단계는 자동 환불됩니다. 계산은 `apps/server/pricing.js`에 있습니다.

## 🚀 실행

Node.js 20 이상, npm, 최종 MP4를 위한 FFmpeg가 필요합니다.

```bash
npm install
cp .env.example .env    # PowerShell: Copy-Item .env.example .env
npm run dev
```

`http://localhost:5173` 접속. `.env`에 `DEEPSEEK_API_KEY`, `KIE_API_KEY`가 필요합니다.
