## 📌 개요

질문 다섯 개(**스토리 → 애니메이션 기법 → 캐릭터 → 장면 수 → Launch**)에 답하면 AI가 스토리를 다듬고, 캐릭터를 만들고, 스토리보드를 그리고, 장면마다 영상을 만들어 하나의 MP4로 합칩니다. 가장 싼 모델을 쓰고, **AI를 쓴 만큼 원가 + 20%로 크레딧이 차감**됩니다.

---

## 🧭 사용 방법

| 단계 | 내용 |
|---|---|
| 1. 스토리 | 500자 이내로 대충 써도 AI가 개선 |
| 2. 애니메이션 기법 | 강한 훅 · 반전 엔딩 · 무한 루프 · 감동 · 코미디 · ASMR |
| 3. 캐릭터 | 설명하면 예시 캐릭터를 보여주고, 그대로 쓰거나 수정 요청 |
| 4. 장면 수 | 7 · 10 · 13개 (장면당 3~7초) → 스토리보드 확인 |
| 5. Launch | 장면 영상 생성 → 최종 MP4 |

언어: 한국어, English (US / India), हिन्दी, Español, 日本語, Bahasa Indonesia — 화면과 생성되는 스토리·자막 모두 선택한 언어로 나옵니다.

## 💰 가격

미리 결제하지 않고, **AI를 쓴 만큼 크레딧이 차감**됩니다. DeepSeek 토큰 수와 Kie AI `creditsConsumed`(각 회사의 실제 사용량 기록) 기준으로, AI 호출이 끝날 때마다 바로 빠집니다.

```text
차감 크레딧 = 올림(AI 원가(달러) × 환율 × (1 + MARKUP))      1크레딧 = 1원
```

`MARKUP` 기본값은 **20%**이고 `.env`에서 올릴 수 있습니다(20% 밑으로는 안 내려감).

| AI 호출 | 원가 | 고객 차감 (+20%) |
|---|---|---|
| DeepSeek 텍스트 (스토리·장면 설계) | 입력 100만 토큰당 $0.56 · 출력 100만 토큰당 $1.68 | 쓴 토큰 × 단가 × 1.2 |
| Z-Image 캐릭터 그림 | 장당 $0.004 | 7원 |
| Seedream 스토리보드 (10장면당 1장) | 장당 $0.0162 | 28원 |
| Seedance 장면 영상 (480p) | 초당 $0.00875 (클립당 4~12초) | 초당 약 14.7원 |

장면당 평균 5초면 영상 한 편에 약 **580원(7장면) ~ 1,060원(13장면)**, 다시 만들기는 별도입니다.

- 단계를 시작하기 전에 잔액이 그 단계의 **최대 예상치**(가장 긴 영상, DeepSeek 최대 출력)보다 많아야 합니다. 화면에는 "최대 ○○원"으로 표시되고, 실제로는 쓴 만큼만 빠집니다.
- AI 회사가 청구하지 않은 실패는 차감되지 않으므로 환불 처리가 필요 없습니다.
- 사용 내역에 AI 호출마다 토큰 수와 차감액이 남습니다. 계산은 `apps/server/pricing.js`에 있습니다.

## 🚀 실행

Node.js 20 이상, npm, 최종 MP4를 위한 FFmpeg가 필요합니다.

```bash
npm install
cp .env.example .env    # PowerShell: Copy-Item .env.example .env
npm run dev
```

`http://localhost:5173` 접속. `.env`에 `DEEPSEEK_API_KEY`, `KIE_API_KEY`가 필요합니다.
